# Библиотека - CRUD приложение (Express + EJS + PostgreSQL)

## Короткое описание

Веб-приложение для управления библиотечной системой с использованием Node.js, Express, EJS и PostgreSQL. Реализует полный CRUD-функционал для работы с книгами и выдачами, включает систему отчётов.

## Технологии

- **Node.js** — серверная платформа
- **Express** — веб-фреймворк
- **EJS** — шаблонизатор для генерации HTML
- **PostgreSQL** — реляционная база данных
- **body-parser** — обработка тела запросов
- **method-override** — поддержка PUT/DELETE методов в формах
- **pg** — драйвер PostgreSQL для Node.js

## Структура базы данных

### Таблицы:

**Книги (Книги):**
- `isbn` — ISBN книги (первичный ключ)
- `Название` — название книги
- `Автор` — автор
- `Год_издания` — год издания
- `Жанр` — жанр
- `Цена_книги` — цена

**Выдачи (Выдачи):**
- `id` — ID выдачи (первичный ключ)
- `id_читателя` — ID читателя
- `isbn` — ISBN книги (внешний ключ)
- `id_библиотекаря` — ID библиотекаря
- `Дата_выдачи` — дата выдачи
- `Дата_возврата` — дата возврата

## Установка и настройка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/denisunderonov/tablesEJS.git
cd tablesEJS
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить PostgreSQL

Создайте базу данных и таблицы:

```sql
-- Создать базу данных
CREATE DATABASE postgres;

-- Подключиться к базе
\c postgres

-- Создать таблицу Книги
CREATE TABLE Книги (
    isbn VARCHAR(20) PRIMARY KEY,
    Название VARCHAR(255) NOT NULL,
    Автор VARCHAR(255) NOT NULL,
    Год_издания INTEGER,
    Жанр VARCHAR(100),
    Цена_книги DECIMAL(10, 2)
);

-- Создать таблицу Выдачи
CREATE TABLE Выдачи (
    id SERIAL PRIMARY KEY,
    id_читателя INTEGER NOT NULL,
    isbn VARCHAR(20) REFERENCES Книги(isbn),
    id_библиотекаря INTEGER NOT NULL,
    Дата_выдачи DATE NOT NULL,
    Дата_возврата DATE
);

-- Добавить тестовые данные (опционально)
INSERT INTO Книги (isbn, Название, Автор, Год_издания, Жанр, Цена_книги) VALUES
('978-5-17-123456-7', 'Мастер и Маргарита', 'Булгаков М.А.', 1967, 'Роман', 450.00),
('978-5-17-234567-8', 'Преступление и наказание', 'Достоевский Ф.М.', 1866, 'Роман', 500.00);
```

### 4. Настроить подключение к БД

Отредактируйте `index.js`, строки 16-22:

```javascript
const pool = new pg.Pool({
  user: "postgres",           // Ваш пользователь PostgreSQL
  host: "localhost",          // Хост БД
  database: "postgres",       // Имя базы данных
  password: "ВАШ_ПАРОЛЬ",     // Ваш пароль
  port: 5432,                 // Порт PostgreSQL
});
```

### 5. Запустить приложение

```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:4555`

## Использование

### Главная страница (`/`)
- Отображает две таблицы: Книги и Выдачи
- Кнопки для добавления, редактирования и удаления записей

### Добавление книги (`/addBook`)
- Форма для ввода данных о книге
- Поля: ISBN, Название, Автор, Год, Жанр, Цена

### Редактирование книги (`/updateBook/:isbn`)
- Форма с предзаполненными данными книги
- Возможность изменить все поля

### Добавление выдачи (`/addIssue`)
- Форма для создания записи о выдаче
- Поля: ID читателя, ISBN, ID библиотекаря, даты

### Отчёты (`/reports`)
- Список всех выдач с деталями
- Общая стоимость выданных книг

## API Endpoints

### Книги:
- `GET /` — главная страница (список книг и выдач)
- `GET /addBook` — форма добавления книги
- `POST /addBook` — создать книгу
- `GET /updateBook/:isbn` — форма редактирования
- `POST /updateBook/:isbn` — обновить книгу
- `DELETE /deleteBook/:isbn` — удалить книгу

### Выдачи:
- `GET /addIssue` — форма добавления выдачи
- `POST /addIssue` — создать выдачу
- `GET /updateIssue/:id` — форма редактирования
- `POST /updateIssue/:id` — обновить выдачу
- `DELETE /deleteIssue/:id` — удалить выдачу

### Отчёты:
- `GET /reports` — просмотр отчётов
